# FlowBucks — Expenses Filter/Search Screen

Static HTML/CSS build of the FlowBucks "Expenses" filter & search screen (desktop), converted from Figma.

**Figma source:** https://www.figma.com/design/ZxGGtFxvVMlnWV3aUkhx7g/FLOWBUCKS-LANDING-PAGE?node-id=227-26

## Design tokens
- Display font: `Cormorant Infant`
- Body/UI font: `Inter`
- Primary blue: `#1E6FD9`
- Background: `#F7F9FA`
- Text: `#0D1B2A`

## Run locally
Just open `index.html` in a browser — no build step required.

## Structure
```
index.html   → markup for header, search bar, filters sidebar, expenses table, pagination
style.css    → all styling (design tokens as CSS variables at the top)
```
